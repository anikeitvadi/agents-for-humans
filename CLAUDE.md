# Working in this repo

This is the workspace for the AWS "Agents for Humans" hackathon (Strands Agents SDK, due Mon Sep 14, 2026, 5pm PT). Two builders: Ani (owner) and a partner.

Read in this order at session start: `HANDOFF.md` (state and open decisions), `docs/brief.md` (what to build and submit, rules, dates), `docs/ideas-discussed.md` (what has already been proposed and the verdicts, so nothing gets re-pitched), `docs/draft-board.html` (the ranked candidates with evidence). Raw research reports are in `research/`.

Rules for this repo:
- Until an idea is chosen, the job is helping the two humans decide, not building. When they choose, write the skeleton, the architecture diagram, and the plan first, then code.
- The agent must be NEW code written inside the submission window. If anything is reused from Ani's other repos (jobsearch-cli logic, the moneylines calibration scripts), list it in the README under "Pre-existing code" per the rules.
- Nothing personal goes in here: no job-search data, no betting tickets, no bankroll, no immigration documents. `private/` is gitignored for scratch material.
- Strands Agents SDK is the required framework. AgentCore is optional but scores. Verify current SDK docs before writing agent code; do not write Strands APIs from memory.
- Keep replies short. Ani flags verbosity fast. Lead with the answer.
- Update `HANDOFF.md` at the end of every session: state, what changed, what is waiting on the humans, next in order.
