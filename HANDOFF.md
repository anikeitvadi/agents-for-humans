**F1–F5 fixed (2026-09-10), TDD throughout (regression test written and confirmed RED before each fix):**
- F1: `check_bulletin_cutoff` now requires priority date strictly before the cutoff (`<`, not `<=`); equality is `not_current`.
- F2: `extract_fields` now requires and sends `modelId` to Bedrock Converse. Added a botocore-schema-validating fake client (`tests/test_extraction.py`) so a missing required request param fails the suite, not just live calls.
- F3: `Store.save_alert` is now an atomic guarded UPSERT: a persisted `silent` row can transition to `surfaced` (previously stuck forever because the second INSERT silently failed on the PK conflict); a `surfaced` row is sticky and never downgraded; true no-op duplicates still return `False`. Also fixed a related bug this exposed — failed INSERTs weren't rolled back, leaving an open transaction that deadlocked a second connection on process restart. `_already_surfaced` (decision_gate.py) now matches on `rule_version` too, so a rule-version bump isn't silently suppressed by an older version's surfaced alert.
- F4: `extract_fields` now validates response shape end-to-end — malformed envelopes, non-dict JSON, and null field entries no longer crash; unsupported status values and "extracted" fields with a null value or empty evidence are downgraded to `ambiguous` and force `needs_review` (previously could return `needs_review=False` on a null value).
- F5: `ui/index.html` no longer interpolates any API/model text into `innerHTML`; all dynamic values render via `textContent`/DOM node construction, closing the HTML-injection gap.
