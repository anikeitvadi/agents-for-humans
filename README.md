# Agents for Humans · hackathon workspace

Research, decision trail, and (once chosen) the build for the AWS Agents for Humans hackathon (Strands Agents SDK, due Sep 14, 2026).

- `HANDOFF.md`: where things stand and what's waiting on us
- `docs/brief.md`: what to build, what to submit, the rules, the dates
- `docs/ideas-discussed.md`: every idea proposed so far and its verdict
- `docs/draft-board.html`: the ranked candidate board with evidence (open in a browser)
- `research/`: five research reports, ~30 candidate workflows with sources
- `agent/`: the build lands here
